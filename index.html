        Récupérer tes pas depuis Apple Santé

        Une page web ne peut pas lire Santé directement. Un raccourci, créé une seule fois, s'en charge :

        1. Dans l'app Raccourcis, crée un raccourci nommé « Pas Ramasse ».
        2. Ajoute l'action Santé Rechercher des échantillons : type Nombre de pas, date de début dans les 2 dernières heures (adapte à ta sortie).
        3. Ajoute Calculer des statistiques : Somme des échantillons.
        4. Ajoute Copier dans le presse-papiers.

        Après un ramassage, lance-le puis colle le résultat dans « Pas ». Sur Android, recopie le chiffre depuis Google Fit ou Samsung Health.
